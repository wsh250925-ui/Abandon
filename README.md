# 健康学院急救学习小程序

本项目面向约 500–1000 人的急救知识学习与科普，提供视频和图文学习、选择题测试、学习进度与排行榜、AED 地点查询及 120 拨号入口。无付费功能。现有版本为可运行的开发初版，上线仍需完成真机验收、内容确认和平台发布配置。

## 代码目录

- `miniprogram/`：小程序页面、自定义 TabBar、图片与工具函数。
- `cloudfunctions/learningApi/`：用户、课程、习题、进度、排行榜与开发者管理接口。
- `cloudfunctions/aedApi/`：百度 AED 地点检索和路线时间查询。
- `security/`：数据库和云存储权限模板。
- `tests/`：学习业务与图文图片回归测试。
- `docs/`：三人分工计划、维护说明、更新记录及可编辑 Word 文档。

## 本地验证

在项目目录执行 `node --test tests/*.test.js`。自动化测试包含实际报错 URL 的恢复、后台保存地址处理、文章多图顺序、加载失败处理和学习去重计时等场景。测试使用云接口模拟，不替代登录云环境后的真实文件读取与手机验收。

## 协作与转交

代码可以打包或通过私有 Git 仓库转交。编写项目安排的人优先接收 `docs/TEAM_PLAN.md` 和需求摘要即可；参与开发者需要代码与接入说明。数据库、云存储文件、云函数环境变量不包含在代码目录中，必须另行授权访问或导出。百度 AK 与管理员白名单配置只保存在云函数配置中。具体交接清单见分工计划第六页。
