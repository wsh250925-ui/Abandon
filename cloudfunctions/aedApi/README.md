# aedApi 部署说明

在云开发控制台进入 `aedApi` 云函数，设置环境变量：

```text
BAIDU_MAP_AK=百度地图开放平台服务端 AK
```

百度 AK 只配置在云函数环境变量中，不要写进小程序前端。需要为 AK 开通地点检索和轻量级步行/驾车路线规划服务。

部署后，在微信开发者工具右键 `cloudfunctions/aedApi` 上传并部署：云端安装依赖。

## 运行链路

- 小程序先用 `wx.getLocation({ type: 'gcj02' })` 获取当前位置。
- `search` 调用百度地点检索，查询 `AED` 与“自动体外除颤器”，按 1/3/5 公里半径返回结果。
- 云函数在返回前重新计算距离并过滤非 AED 名称，前端只展示有限数量的点位。
- 用户点选设备后，`routes` 调用百度轻量级步行、驾车路线接口，返回预计距离和耗时。
- “导航前往”使用微信 `wx.openLocation` 打开系统地图；百度 AK 不暴露给小程序前端。

## AK 与环境变量

百度开放平台应用类型选择“服务端”，启用地点检索、轻量级步行路线规划、轻量级驾车路线规划。测试阶段可使用 IP 白名单 `0.0.0.0/0`，正式上线应收紧到云函数固定出口 IP，或改为服务端 SN 校验并同步修改 `index.js`。

CloudBase 控制台路径：`云函数 → aedApi → 函数配置 → 环境变量`。

```text
BAIDU_MAP_AK=百度服务端AK
```

不要把 AK 写入 `miniprogram` 文件，也不要提交到 Git。百度 POI 仅代表公开地图信息，不代表 AED 实时可用，页面已显示相应提示。

## 项目其他维护说明

图文图片的存储、旧签名 URL 自动恢复与失败重试见 `docs/ARTICLE_MEDIA.md`。该链路由小程序前端和 `learningApi` 管理数据，与百度 AK 及 `aedApi` 无关。
